本指南专为日常使用可道云办公的**普通员工与个人用户**编写，不涉及任何服务器部署或运维配置。只需 5 分钟，即可像操作 Windows 桌面一样高效管理云端文件。

## 第 1 步：登录网盘并认识工作区

从管理员处获取网盘网址与账号密码，打开浏览器登录即可进入工作区（完整登录与界面说明见 [1 系统登录](/user/1/) 与 [2.1 菜单栏](/user/2.1/)）：

- **桌面 / 文件管理**：类 Windows 桌面与资源管理器体验，支持右键菜单、框选多选、拖拽移动与双栏分屏浏览。
- **个人空间**：仅你自己可见的私有存储区域，用于存放个人草稿与待整理资料。
- **企业网盘 / 部门空间**：按组织架构划分的团队共享空间，你的读写权限由管理员或部门负责人配置。
- **快捷入口**：左侧导航栏支持「收藏夹」「我的标签」「我的分享」「最近文档」与「回收站」一键直达。

## 第 2 步：拖拽上传与高频快捷键

- **极速上传**：直接将电脑中的单个文件或整个文件夹拖入浏览器窗口即可自动上传；相同文件会自动触发**秒传**，无需重复等待。
- **常用效率快捷键**（与本地桌面高度一致，完整列表见 [快捷操作](/start/3/)）：
  - `Ctrl + A` 全选、`Ctrl + C` / `Ctrl + X` / `Ctrl + V` 复制/剪切/粘贴
  - `F2` 重命名、`Delete` 移入回收站、`Enter` 快速打开或在线预览
  - `Ctrl + F` 在当前目录快速检索文件名、拼音或文件内容

## 第 3 步：用好标签、保险箱与在线预览

1. **多维文件标签**：一份文件无需到处复制，右键为其打上彩色标签（如「待审批」「高优先」「2026项目」），即可在左侧「标签」中跨目录聚合查看（详见 [文件标签技巧](/start/articles/1/)）。
2. **个人保险箱**：将工资条、证件扫描件等高敏个人文件放入加密保险箱，需单独输入二次密码解锁访问。
3. **在线预览与协同编辑**：双击即可在线预览 Office、PDF、音视频、代码与设计稿（完整格式清单见 [在线预览格式支持](/start/2/)）；若管理员已配置 OnlyOffice，右键即可多人实时在线编辑 Word/Excel/PPT，并支持**文件编辑锁**防止多人覆盖冲突（详见 [文件编辑锁](/start/articles/3/)）。

## 第 4 步：团队协作、版本历史与外链分享

- **对内协作分享**：右键文件夹 → **协作分享**，直接指定同事或部门并赋予「预览者 / 上传者 / 编辑者」权限，避免在聊天群反复传附件。
- **对外加密外链**：右键文件 → **外链分享**，可设置提取密码、有效期、下载次数上限、禁止下载仅预览或文档发布模式，随时可在「我的分享」中一键取消。
- **历史版本回溯**：误改重要文档后，右键文件 → **历史版本**，即可查看历次保存记录并一键恢复。

## 第 5 步：连接 PC 客户端与手机 App

- **电脑端办公**：安装官方 PC 客户端，支持本地自动挂载云盘目录、指定目录同步，以及直接调用本机 Office/CAD/PS 打开云端文件并保存回写（详见 [PC 客户端安装与使用](/user/PC/6.1/)）。
- **手机端与相册备份**：安装 iOS / Android 客户端，可随时查阅审批文件并开启**手机相册自动备份**（详见 [移动端 App 指南](/user/app/7.1/)）。

## 验证你已上手（Success Check）

完成以下三件小事，即表示你已掌握日常办公核心操作：

1. 将本地一个文档拖入「个人空间」并双击成功在线预览。
2. 为该文档打上一个颜色标签，并用顶部搜索框通过文件名找到它。
3. 为该文档生成一个带密码和有效期的测试外链，在浏览器无痕窗口中成功打开后再取消分享。
