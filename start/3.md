## 鼠标操作

| 动作 | 鼠标快捷操作 |
| --- | --- |
| 选择文件 | 框选任意文件 |
| 收藏文件 | 拖拽文件（夹）→收藏夹 |
| 添加标签 | 拖拽文件（夹）→目标标签 |
| 删除文件 | 拖拽文件（夹）→回收站 |
| 更多操作 | 鼠标右键 |

## 组合快捷操作

按住 Ctrl 或 Shift 配合鼠标，可快速复制、移动和批量选择：

| 动作 | 快捷操作 |
| --- | --- |
| 在当前目录复制 | Ctrl+鼠标拖拽（选中后） |
| 移动文件到其他目录 | Ctrl+鼠标拖拽（选中后） |
| 点选 | Ctrl+鼠标点击选中 |
| 连续选择 | Shift+文件首尾点击 |
| 右键菜单快捷操作 | Alt+鼠标右键菜单项 |

## 快捷键操作

常用键盘快捷键（Mac 用户将 Ctrl 换为 Command）：

| **动作** | **快捷键** |
| --- | --- |
| 打开 | Enter |
| 全选 | Ctrl+A |
| 复制选中 | Ctrl+C |
| 粘贴 | Ctrl+V |
| 剪切 | Ctrl+X |
| 当前目录进行搜索 | Ctrl+F |
| 新建文件 | Ctrl+N |
| 新建文件夹 | Ctrl+M |
| 删除选中 | Delete |
| 永久删除选中 | Shift+Delete |
| 属性 | Alt+I |
| 前进 | Ctrl+Backspace |
| 后退 | Backspace |
| 重命名选中 | F2 |
| 选择文件 | Home, End, PageUp, PageDown up↑ down↓ left ← right→ |
| 文件首字母自动循环选中 | 任意数字或字母 |
| 拼音模糊搜索 | 中文名称首字母 |
