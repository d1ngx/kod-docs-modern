| 特性 | 特性描述 |
| --- | --- |
| Web/H5 | ● 随时随地，通过浏览器直接访问；<br>● 内容显示自适应终端状况，页面布局根据屏幕大小自动调整；方便快捷集成/嵌入到企业 APP、公众号或其他系统；<br>● 支持 IE9 及以上版本、Firefox、Chrome、Safari 以及市场上其它主流的浏览器访问 |
| 多终端支持 | ● 浏览器：Web/H5<br>● PC 客户端：Windows、Mac、Linux<br>● 移动端 APP：Android、iPhone、iPad |
| 自动备份 | ●Windows、Mac客户端指定文件夹自动备份数据到云端文件夹，本地变化的文件更新到云端，但云端变化不影响本地<br>● 增量内容自动备份，保证本地重要数据安全 |
| 相册备份 | 移动端APP支持相册自动备份（Android、iPhone、iPad） |
| PC传输管理 | ● 客户端支持文件下载传输管理，支持查看下载任务进度、暂停、开始或删除任务、打开本地或远端文件夹等操作<br>● 支持对客户端开启启动、下载线程、保存路径、缓存处理等项目进行设置 |
| PC本地打开 | ● Windows、Mac客户端支持调用PC软件对在线文件进行预览、编辑；<br>● 自动加载到本地，并调用本地默认打开方式打开<br>●本地原生态编辑体验，文档保存后自动上传，并生成历史记录 |
| WebDAV协议 | ● 支持PC、手机或TV 应用挂载，高度通用性，本地化操作体验<br>● 挂载后文档权限完全同Web端权限逻辑保持一致，无越权之忧 |
