<div id="start" class="tab-pane fade in active" markdown="1">

| 特性 | 特性描述 |
| --- | --- |
| 统计面板 | ● 用户注册数，在线情况，文件数，个人及部门空间用量及排序等，一目了然<br>● 用户数据报表概览，对全局使用情况了如指掌<br>● 操作系统环境、系统磁盘空间、网络挂载使用等运维信息 |
| 系统通知 | ● 支持拟定消息/通知后推送，支持对消息/通知进行排版<br>● 可设置推送对象（指定用户、部门、权限组的组合或所有人）和推送形式（立即推送、计划推送） |
| 用户注册 | 支持开启用户自助注册。提供注册管理设置选项，是否开启审核，默认用户组，默认所在部门等 |
| 高度自定义 | ● 模块化配置：前端显示模块化组合，可灵活自定义是否显示个人空间、企业空间或部门空间、标签、挂载、分类等多模块<br>● 菜单管理：自定义主界面菜单，可针对用户或部门进行开启；<br>● 邮箱自定义 |
| 服务器配置 | 支持在后台对服务器配置情况进行管理，如系统缓存设置等 |
| 计划任务 | 支持在后台对文件备份等进行中计划任务进行管理，快捷管理系统进行中的任务 |
| 任务管理器 | 管理员可通过任务管理器对正在进行中的任务（文件传输、压缩解压等）进行查看、中止等操作 |

</div>
