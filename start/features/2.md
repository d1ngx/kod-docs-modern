| 特性 | 特性描述 |
| --- | --- |
| 断点续传 | 支持从文件上次中断的地方开始传送数据，而非从头传送 |
| 秒传/极速上传 | 对于系统中任何人已上传的文件，FileMatch智能识别，分秒之间完成传输；无论文件大小，系统中重复文件只需传输一次，节省企业带宽资源，提升上传体验 |
| FileMatch智能识别 | 修改文件名不影响秒传、文件去重功能 |
| Easytrans上传优化 | 大文件上传优化、多文件上传优化；浏览器支持10万级文件（夹）上传 |
| 文件去重 | 支持后台跨用户文件去重，支持不获取用户文件明文的前提下去重；大量数据拷贝复制不占空间，极大节省企业存储空间成本 |
| 高效移动 | 系统内移动10000个文件仅需5s（不论文件大小），提升文件管理效率 |
