<div id="start" class="tab-pane fade in active" markdown="1">

| 特性 | 特性描述 |
| --- | --- |
| 部门管理 | ● 多部门分区分级灵活管理，满足不同组织架构及部门对内对外文档权限设置需求；<br>● 当集成AD/LDAP、钉钉、企业微信等统一用户认证体系时，自动同步组织架构和用户信息，无需单独重新配置账户信息（用户名、密码、部门组织机构等）。 |
| 成员管理 | ● 支持用户批量导入、删除、启用/禁用等操作；<br>● 支持批量添加到/移除部门、设置权限角色、空间大小设置等；<br>● 用户可以归属多部门，支持用户属性修改，设置部门中管理权限等 |
| 容量限制 | 管理员可灵活修改成员空间及组织架构空间配额 |
| 成员/部门搜索 | 支持按照成员姓名或登录名搜素，支持模糊搜素 |
| 角色权限 | 前台文档操作、后台管理系统等分别对应几十种超细粒度模块化权限配置，可灵活赋予多种角色配置 |
| 文档权限 | ● 支持细颗粒级文档权限设置，提供文件列表，文件预览，下载/复制，上传，编辑新建，删除，分享，文档评论，文档动态等10多类权限模块，可根据管理实践自行组合各类文档策略<br>● 文档权限组合可应用于部门权限、文档权限、协作权限设置，简明易用 |

</div>
