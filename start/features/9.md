可道云提供多端访问能力，支持 Web、PC 客户端和移动端。下表列出相关特性：

<div id="start" class="tab-pane fade in active" markdown="1">

| 特性 | 特性描述 |
| --- | --- |
| 平台兼容性 | 支持不同品牌、型号的硬件设备、无需绑定特定或指定品牌硬件设备；全面支持国产信创平台 |
| 环境兼容性 | Windows/Linux/Mac系统全平台适应；全面支持国产信创系统 |
| 企业形象自定义 | 自定义Logo、网盘名称，登录页面背景等（WEB、H5页面、PC客户端内页） |
| 架构/负载均衡 | ● 系统整体架构采用面向服务的技术架构（SOA），可以根据需求通过网络对松散耦合的粗粒度应用组件进行部署、组合和使用，提供负载均衡与高可用设计。<br>● 支持负载均衡，确保系统的高可用和高性能。 |
| 容器化支持 | ● 支持Docker容器化部署；支持Swarm/Kubernetes容器集群<br>● 基于容器的微服务架构，实现应用服务的松耦合，服务独立开发/部署/演进和伸缩 |
| 多云融合存储 | ● 系统支持与亚马逊S3、阿里云OSS、七牛、腾讯云、天翼云、百度云、XSKY、Minio等多个通用对象存储快捷对接<br>● 支持服务器本地挂载、FTP挂载、对象存储挂载等多种类、多存储同时挂载，轻松实现混合存储<br>● 不同挂载存储之间可以相互拷贝、粘贴、拖拽，轻松实现存储跨云端数据管理及流转<br>● 通用存储IO驱动，可提供其他第三方对象存储对接开发服务 |
|  | ● 挂载存储中文件支持直接进行在线文件管理，支持在线预览/编辑、压缩解压等<br>● 支持对挂载存储中文件进行外链分享、内部协作分享；协作分享支持指定任意用户和部门分别设置权限 |
| SSO单点登录集成 | ●共享登录，用户单点登录集成；<br>●支持与公司统一身份认证中心集成，实现统一登录（提供按需对接开发服务） |
| 钉钉集成 | 插件化支持钉钉用户及组织架构集成，实时同步；钉钉扫码登录 |
| 企业微信集成 | 插件化支持企业微信用户及组织架构集成，实时同步；企业微信扫码登录 |
| AD/LDAP协议对接 | 插件化支持LDAP/AD 域用户及组织架构集成 |
| 第三方快捷登录 | 插件化支持可提供QQ，微信，github等第三方登录方式对接开发服务 |
| 插件市场 | ●30+插件支持，持续升级更新；<br>●开放插件开发文档，企业可根据需求以插件形式灵活进行功能拓展 |
| 开放API | 开放API接口，提供开发文档；方便集成其他企业应用 |
| 通用文件预览组件 | 支持100多种格式在线预览，供第三方系统或模块调用，为企业提供统一的基础文档预览能力支撑 |
| Office在线编辑组件 | 支持Office文件在线编辑，供第三方系统或模块调用，为企业提供统一的Office文档在线编辑支撑 |
| 多语言 | 自动匹配语言界面，支持中英等20多种语言；方便全球化使用（提供语言包定制服务） |
