可道云面向不同规模与交付场景提供 **KodBox 开源免费版**、**KodBox 企业/商业授权版** 以及软硬一体开箱即用的 **teamOS** 三种形态。本文档站不拆分多套容易脱节的手册，而是通过页面顶部的内联标签精确标明每项功能的版本与授权要求。

## 文档内联标签说明

在阅读本文档时，页面标题下方可能出现以下四类语义标签：

| 标签示例 | 分类 | 含义说明 |
| --- | --- | --- |
| `新手教程` / `实战指南` / `核心原理` / `技术参考` | 文档类型 | 遵循 Diátaxis 四象限，帮助你快速判断本页是单路径学习、任务实操、原理解析还是参数字典 |
| `开源版` / `企业版` / `teamOS` | 授权范围 | 标注该能力适用的产品版本；仅标 `企业版` 的能力需商业授权或单独购买对应商业插件 |
| `v1.70+` / `v1.70.03+` | 最低版本 | 该特性或安全修复引入的最低 KodBox 版本号，低版本用户请先参考 [版本升级指南](/operations/upgrade/) |

## 三种产品形态对比

| 能力维度 | KodBox 开源版 | KodBox 企业版 | teamOS |
| --- | --- | --- | --- |
| **核心定位** | 个人 NAS、极客、小微团队自托管 | 中大型企业私有云协同与合规管控 | 预装优化的一体化 NAS/服务器操作系统 |
| **交付方式** | Docker 镜像 / 源码安装包（LNMP） | 开源底座 + 企业授权激活与商业插件 | ISO 镜像直装（裸机/虚拟机） |
| **基础网盘与云桌面** | 完整支持 | 完整支持 | 完整支持 |
| **多云对象存储** | 支持本地、FTP、主流 S3/OSS/COS | 支持全量对象存储与高级存储策略 | 完整支持 + 图形化 RAID 与磁盘管理 |
| **在线办公（OnlyOffice）** | 支持（OnlyOffice 插件 v2.06+ 已免费开放） | 支持 + 更多文档协同与转换引擎 | 支持 |
| **权限与安全管控** | 基础角色、部门与文档权限、2FA | 增强审计、动态水印、登录管控、细粒度策略 | 依所激活授权等级 |
| **企业集成与检索** | WebDAV、Samba 等基础插件 | AD/LDAP、企微/钉钉同步、全文检索、AI Pro 自定义模型 | 依所激活授权等级 |
| **典型硬件管理** | 依赖宿主机 OS / NAS 系统 | 依赖宿主机 OS / 容器编排 | 内置磁盘 RAID、NFS 挂载与网络配置面板 |

> **提示**
>
> OnlyOffice 插件自 `v2.06` 起已免费开放，配合 OnlyOffice Docs 9.4+ 社区版（已取消 20 并发连接限制），开源版用户亦可零授权成本搭建完整在线文档编辑能力，详见 [OnlyOffice 组件部署与集成](/setup/office/)。

## 配置优先级说明

在运维 KodBox 时，部分参数同时存在于环境变量、PHP 配置文件与管理后台界面中。排查配置不生效时，请按以下覆盖顺序核对：

1. **数据库系统配置表（管理后台界面修改）**：绝大多数业务设置（如分片大小、上传白名单、插件配置、水印策略）保存在数据库 `system_option` 表中，优先级高于默认配置。
2. **`config/setting_user.php` 用户自定义文件**：用于覆写数据库连接、缓存驱动（Redis/File）、全文检索开关等底层系统参数，升级程序时不会被覆盖。
3. **容器环境变量（Docker `MYSQL_*` / `REDIS_*` / `PUID` / `PGID`）**：主要在容器首次初始化及进程启动阶段注入运行环境与属主权限。
