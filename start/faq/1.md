以下为新用户常见问题解答。

### 如何注册 KODBOX 账号？

账号通常由管理员统一创建和分配，请咨询单位管理员获取账号信息。

若管理员开启了自助注册，您可在登录页通过微信、QQ、邮箱或手机等方式自行注册。

若单位已对接 AD/LDAP 域控、企业微信或钉钉，则可直接使用企业账号登录，无需额外注册。

### 如何登录可道云？

可道云支持多种访问方式：

- **WEB 端**：在浏览器中输入服务器地址（如 `https://demo.kodcloud.com`），输入账号密码登录。
- **PC 客户端**（Mac / Windows / Linux）：安装客户端后输入账号密码；首次使用需填写服务器地址（向管理员索取）。
- **移动端**（Android / iOS）：安装 App 后同样需先配置服务器地址，再登录。

### 个人空间是什么？

- 个人空间是每位员工在企业网盘中的**私有区域**，仅本人可见。
- 其他用户无法查看您个人空间中的文件。
- 空间容量由管理员分配。

### 企业网盘是什么？

企业网盘是**企业公共存储空间**，用于存放公司共享文件（如规章制度、工作规范等）。

新用户默认加入企业网盘分组。拥有者权限的用户可对文件/文件夹设置权限，实现全公司共享。

### 我所在的部门是什么？

部门空间是**本部门成员的协作区域**，仅部门成员可访问。

管理员负责创建部门并分配初始权限。部门拥有者可对部门内文件设置不同成员的权限。

### 个人空间、企业网盘、部门空间的区别

| | 个人空间 | 企业网盘 | 部门空间 |
| --- | --- | --- | --- |
| 用途 | 存放个人文件 | 存放企业公共文件 | 存放部门文件 |
| 可见范围 | 仅本人 | 有权限的成员 | 仅本部门成员 |
| 权限设置 | 不受文档权限限制 | 受角色+文档权限限制 | 受角色+部门+文档权限限制 |

### 与我协作是什么？

当您需要将文件夹共享给他人协作时，在「我的文档」或「企业网盘」中选择文件夹，使用「内部协作分享」即可。

被分享的用户可在「与我协作」中看到他人向自己发起的协作文件夹。

例如：不同项目组各建一个协作文件夹，仅项目成员可访问，实现文件隔离与分类管理。
