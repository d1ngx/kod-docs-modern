可道云支持数百种常见文档格式的在线预览。您无需下载到本地或安装专用软件，打开浏览器即可查看。

> Tips
>
> 除在线预览外，所有文档均可通过PC客户端调用本地软件打开，获得熟悉、高效的本地编辑体验。

## 基础/常用格式

| 文件类型 | 具体支持格式 |
| --- | --- |
| 图片 | jpg jpeg png, bmp, gif, ico, svg, cur, webp |
| 音乐/视频在线播放 |  mp3, wav, m4a, aac, oga, ogg, webma, mp4, m4v, flv, mov, f4v, ogv, webm, webmv|
| 版式文档 | PDF，OFD，XPS |
| 在线解压/压缩文件 | zip, tar, gz, tgz, ipa, apk, rar, 7z, iso, epub |
| 电子书、flash | pdf, swf, epub, xps, djvu, fb2 |

## Office 文件

可道云兼容Microsoft Office、WPS、Open Document 等多种Office文档在线预览，支持在线多人协同编辑。同时支持多种Office在线预览/编辑方案（Microsoft Office Online、永中、金山、onlyOffice等）供用户灵活选择和集成。

| 文件类型 | 具体支持格式 |
| --- | --- |
| Microsoft Word | doc, docx, odt, rtf, docm, dotm, dot, dotx |
| Microsoft Excel | xls, xlsx, ods, csv, xlt, xltx, xlsb, xlsm |
| Microsoft PowerPoint | ppt, pptx, pps, ppsx, odp, pot, potx, pptm, ppsm, potm, ppam |
| WPS文档 | wps, wpt, et, ett, dps, dpt |
| OpenDocument | odf, odt, ods, odp |
