### KODBOX 企业网盘是什么？

KodBox 是可道云推出的**企业级私有云存储**产品，帮助中小企业在自有服务器上搭建安全、可控的文件存储与协同办公平台。

简单来说：把公司的文件集中存放在您自己的服务器上，员工通过浏览器或客户端随时访问、协作，数据不出企业。

### 企业网盘与个人网盘有什么区别？

| | 个人网盘 | 企业网盘 |
| --- | --- | --- |
| 面向对象 | 个人用户 | 团队 / 组织 |
| 主要用途 | 存储个人文件 | 团队共享、协作办公 |
| 典型功能 | 上传、下载、分享 | 在线预览编辑、部门权限、审计日志、多端同步等 |

### 可道云与百度网盘、阿里云盘有什么不同？

1. **目标用户不同**：百度网盘、阿里云盘主要面向个人用户；可道云面向企业，在文件存储基础上增加了集中管理、多人协作、细粒度权限等企业特性。

2. **部署方式不同**：百度网盘、阿里云盘等以 SaaS 方式运行，**用户数据存储在服务商的服务器上**。KODBOX 以**私有部署**为主——软件安装在您自己的服务器上，数据由企业自行掌控，私密性和可控性更高。

### 可道云 KodBox 与 KodExplorer 有什么不同？

KodBox 是在 KodExplorer 基础上**全面重构**的新一代产品，面向更高性能、更强安全和更多企业功能的需求。

**架构差异（了解即可）：**

- **KodBox**：采用「数据库 + 文件存储」架构。用户信息、权限、文件关系等存在数据库中；实际文件加密后存在磁盘或对象存储中，通过 ID 关联。
- **KodExplorer**：文件直接按文件夹目录存放，管理员可在服务器上直接看到用户目录结构。

**KodBox 的主要升级：**

- **文件传输**：支持文件去重（相同文件秒传）、大文件分片上传、网盘内快速复制移动。
- **操作体验**：多窗口拖拽、高级搜索、文件分类、文件夹排序等。
- **权限管理**：细粒度文档权限，支持部门内、跨部门及灵活的协作分享（KodExplorer 主要限于个人空间分享）。
- **管理后台**：独立管理界面，含日志审计、计划任务、统计面板等。
- **存储扩展**：支持本地磁盘、FTP、阿里云 OSS、AWS S3、七牛等对象存储，可在不同存储间像「C 盘到 D 盘」一样迁移文件。

KodBox 还提供 PC 客户端、移动端 App、文件备份等功能。

**如何选择？**

- **KodExplorer**：适合个人或小型团队，部署简单。
- **KodBox**：适合有协作、权限、审计需求的企业，可支撑更多用户和更高并发。
