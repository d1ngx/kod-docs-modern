## 1 基础软件环境

| 软件 | 版本 | 说明 |
| --- | --- | --- |
| PHP | 7.4 | 解析PHP程序代码 |
| Nginx | 1.22 | 提供web访问入口 |
| MySQL | 8.0 | 提供数据库结构存储 |
| Redis | 7.0 | 缓存加速，提高读写效率和用户体验 |
| Docker | 20.10 | 用于运行office在线编辑解析服务 |

## 2 防火墙开放端口

| 端口或服务 | 协议 | 说明 |
| --- | --- | --- |
| 80 | tcp | 站点对外访问端口 |
| 8001 | tcp | office在线编辑解析服务运行端口 |
| 9090/cockpit | tcp | 控制面板访问入口 |
| 5353/avahi-daemon | udp | mdns广播，使得可以通过 主机名.local 访问 |
