## 1 基础软件环境

TeamStation 定制设备预装了可道云运行所需的以下软件：

| 软件 | 版本 | 说明 |
| --- | --- | --- |
| PHP | 7.4 | 运行可道云程序代码 |
| Nginx | 1.22 | 提供 Web 访问入口 |
| MySQL | 8.0 | 存储网盘的配置、用户、文件索引等数据 |
| Redis | 7.0 | 缓存加速，提升读写速度和页面响应 |
| Docker | 20.10 | 运行 Office 在线编辑解析服务 |

## 2 防火墙开放端口

如需从其他设备访问相关服务，请确保防火墙已放行以下端口：

| 端口或服务 | 协议 | 说明 |
| --- | --- | --- |
| 80 | tcp | 网盘 Web 站点访问端口 |
| 8001 | tcp | Office 在线编辑解析服务端口 |
| 9090/cockpit | tcp | 硬件控制面板访问入口 |
| 5353/avahi-daemon | udp | mDNS 广播，支持通过「主机名.local」访问设备 |
