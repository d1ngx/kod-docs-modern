## 环境要求
- 激活可道云授权：企业版及以上；[更多了解](https://kodcloud.com/price/)
- 操作系统: CentOS 7+、Ubtntu 14+、Debian 8+、RedHat 7+；***推荐CentOS 7.4 ***
- 服务器内存4G以上；
- 剩余磁盘空间不少于10G；
- 当前登录用户必须是管理员；
- 下面操作不支持运行在虚拟机、或docker或其他虚拟化的系统中。

> 重要：
> 
> 本节仅适用于以及购买可道云企业版授权并激活后的用户。免费用户请忽略本环节。
{: .important}


## 一、安装docker
需要5~10分钟；(若已安装则跳过此步骤)
```
curl -sSL https://get.daocloud.io/docker | sh

# 如果是刚装好系统,需要更新系统软件(该过程会比较慢，中间需要输入"y"确认继续)
yum update && apt-get update
```
## 二、下载相关资源

```bash

# 1.下载相关资源 (复制下面指令粘贴到终端运行)
cd ~ & wget https://static.kodcloud.com/kod/source/onlyoffice/officeData.zip & wget https://static.kodcloud.com/kod/source/onlyoffice/kodoffice.tar

# 2.安装 (复制下面指令粘贴到终端运行)
curl https://doc.kodcloud.com/tools/office/linux/install.sh | sh
```

> 启动 或 重启服务

```
sh ~/run_office.sh

# 安装并启动成功后可以删除 officeData.zip,kodoffice.tar
rm -f ~/kodoffice.tar ~/officeData.zip
```


## 三、配置到可道云
#### 1、安装插件
管理员登陆-界面右上角菜单-**插件中心 (全部)**-找到onlyoffice插件，点击安装

#### 2、配置插件
点击配置插件,将上面office所在服务器ip替换到如图选中的内容(注意结尾/web/不能去除); 

**如果office和可道云部署在同一台服务器，则无需任何配置 。**

点击"检测office服务器"，如果检测通过这说明全部配置完成，刷新可道云页面，选中一个office文件右键打开方式，选择onlyoffice编辑即可体验。
    
![插件设置](/setup/images/2.3/1.png){:width="800px"} 

检测结果无误如下图:
![插件设置](/setup/images/2.3/2.png){:width="600px"} 

!> **注意：**
1. 上面配置ip也可以是绑定了到该服务器的域名，不能为localhost；
2. 不知道如何获取本机ip的，可以通过`ifconfig` 指令查看；
3. 如果网络内、或服务器开启防火墙，导致访问不了，可以尝试关闭防火墙或开启8001端口。


## 四、其他问题

##### 已安装旧版本office，如何升级
 * 重复上面一二三步骤;插件中心必须卸载并重安装『Onlyoffice在线编辑』插件
 * 删除可道云目录 config/setting_user.php 下面以 "define('OFFICE_KOD_"开头的行;

##### 如何配置https访问
 * 若全站采用https访问office，需要配置nginx反向代理来实现https转http
 * 具体实现: [参考这里](/others/office_https.md)

#### 重启系统后如何自启动
 * 安装默认已经加入自启动了；



#### centos 6.x安装docker，按下面进行安装 [说明](https://www.cnblogs.com/zhangzhen894095789/p/6641981.html?utm_source=itdadao&utm_medium=referral)

```
setenforce 0
sed -i '/^SELINUX=/c\SELINUX=disabled' /etc/selinux/config
rpm -iUvh http://dl.fedoraproject.org/pub/epel/6/x86_64/epel-release-6-8.noarch.rpm
yum update -y
yum -y install docker-io
service docker start
chkconfig docker on
docker images
```
