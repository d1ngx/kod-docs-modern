本页汇总 KodBox 近期核心版本（`v1.69` – `v1.70.03`）的关键功能演进、安全补丁与升级注意事项。执行升级操作请对照 [版本升级与变更注意](/operations/upgrade/)。

## v1.70.03（2026 年 10 月）

### 安全加固与底层运行时

- **官方容器镜像升级至修复版 PHP 8.5.12**：`kodcloud/kodbox:1.70.03` 镜像包含最新 PHP 8.5.12 安全修复，建议容器部署用户优先拉取升级。
- **二次验证（2FA）防爆破限流强化**：对二次验证接口增加严格频率限制，阻断暴力猜测动态验证码攻击（详见 [系统安全加固与 2FA 指南](/admin/security-hardening/)）。
- **部门级越权校验增强**：加固多个部门与文档接口的后端权限核验逻辑，封堵跨部门越权访问风险。

### AI 助手与语义检索优化

- **`aiRag` 向量检索文件权限隔离优化**：确保知识库语义召回严格遵循当前登录用户的实时文档权限边界，杜绝无权文件被 AI 间接召回泄露（详见 [AI 助手与 aiRag 语义检索](/admin/aidoc/)）。

## v1.70.x 系列核心演进

### AI 多模态创作引擎

- **统一模型参数配置与多模态调用**：AI 助手插件引入完整的多模态模型调用体系，覆盖文本对话、**ASR 语音转写**、**TTS 语音合成**、**文生图 / 图生图 / 图像编辑**、**文生视频 / 首尾帧视频**以及 **3D 生成**，并完善火山引擎豆包等主流服务商 API 适配。
- **明确区分传统全文检索与 `aiRag` 语义检索**：形成「内置文件名/拼音检索 + MySQL 全文检索 + Milvus 向量语义检索」三层互补架构。

### 在线办公（OnlyOffice 插件）

- **新增显式 JWT 鉴权开关与回调端点鉴权**：管理员可清晰控制 JWT 启用状态，降低迁移后密钥不同步排查难度。
- **二级目录与内网优先地址保留**：改善 KodBox 与 OnlyOffice 同机/内网部署场景下的回环检测失败与回调链路稳定性（详见 [OnlyOffice 部署与安全集成](/setup/office/)）。

### 协议与存储插件

- **Samba 插件回收站重构（破坏性路径变更）**：将原有全局统一回收站重构为**各共享目录内独立的 `.recycle` 回收站目录**，提升多共享目录隔离度。
- **WebDAV 兼容性修复**：修复深层嵌套子目录遍历异常，以及 **RaiDrive 挂载后通过 WPS 编辑保存导致文件被清空** 的经典问题（详见 [WebDAV 实战指南](/admin/webdav/)）。

### 性能与多媒体缩略图

- **ImageMagick 转换稳定性加固**：实现临时目录隔离、命令参数安全转义与转换失败自动重试机制。
