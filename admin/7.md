## 站点迁移概述

可道云支持迁移到任意具备类似运行环境（LNMP：Linux + Nginx + MySQL + PHP）的服务器。迁移主要分两步：

1. **拷贝站点目录**：将整个可道云安装目录复制到新服务器
2. **迁移数据库**：导出 SQL 备份文件，在新服务器上导入（数据库密码可在站点配置文件 `./config/setting_user.php` 中查看）
